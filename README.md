# Jakes Eddy — Portfolio

Strategic & Creative Developer portfolio built with Next.js and Tailwind CSS v4.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Tech Stack

- **Next.js** 16
- **React** 19
- **Tailwind CSS** 4
- **TypeScript**
